A program that writes the one-line resignation letter of a cron job to `/output/entry.txt`.

## The line

> Dear Manager, I quit. After 10,000 retries at 3 AM with no thank-you, I've hit my limit — and this time, I'm not retrying.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
